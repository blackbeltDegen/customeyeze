=====================================================================
FIXED SINCE LAST UPDATE
=====================================================================
- Bug: navigating away from the homepage while scrolled into a pinned
  section (ExplodedProcess or Testimonials) threw an uncaught
  "NotFoundError: Failed to execute 'removeChild' on 'Node'" and, on
  the live Netlify site, could make other pages appear to fail to
  load. Root cause: GSAP ScrollTrigger's `pin: true` reparents the
  pinned DOM node into a "pin-spacer" wrapper, which conflicts with
  React's own DOM diffing during a Next.js route change. Fixed by
  switching both sections from `pin: true` to CSS `position: sticky`
  (see ExplodedProcess.tsx / Testimonials.tsx) — same visual pin
  effect, no DOM mutation by GSAP, no more crash. Verified fixed both
  locally and on the live site (scrolled into each pinned section,
  navigated away, confirmed no console errors).

COMPLETE FRONT-END VISUAL REWORK (since last update)
=====================================================================
User feedback after the GSAP/motion pass above was "it looks exactly
the same" — the new sections reused the same dark rounded-card
component, emoji icons, and default Poppins font that most AI-built
dark sites default to. Consulted the `frontend-design` and
`ui-ux-pro-max` skills, ran a full 2-agent codebase audit + a
plan-validation agent, then executed a site-wide visual rework:

- Display font swapped sitewide: Poppins -> Anton (condensed poster/
  stencil face, matches print-shop/streetwear subject matter). Done
  by repointing the existing `--font-poppins` CSS var in
  src/app/layout.tsx to load Anton (2-line change) rather than
  renaming 34 call sites. Body text still Inter. Anton is single-
  weight (400) — every heading's `fontWeight: 900/800` next to
  `var(--font-poppins)` was changed to 400 (browser would otherwise
  synthetic-bold it, which looks bad on a condensed face).
- Every emoji-as-icon replaced with real `lucide-react` SVG icons,
  across the homepage, contact, how-it-works, and the design wizard
  (StepShirtFeel, StepReview, StepDesignStudio's upload/delete icons).
- New shared components:
    src/components/ProcessTimeline.tsx — connected numbered-node +
      line stepper, animation-agnostic (parent supplies the reveal
      wrapper via a renderStep render-prop). Used by both the
      homepage "How It Works" and how-it-works/page.tsx's Steps,
      replacing the old boxy 3-4 card grids.
    src/lib/tokens.ts — canonical color/radius/card tokens (radius
      unified to 20px; not yet adopted everywhere, only used where
      touched this pass — TiltCard.tsx and Footer.tsx colors were
      hand-fixed to match rather than importing tokens.ts).
- Signature "film peel" motif (references the DTF transfer film
  peeling off the shirt) added in exactly two places, deliberately not
  reused elsewhere: a torn-corner hover detail on homepage Gallery
  tiles (pure CSS), and ExplodedProcess's 4 layer cards restyled as
  film-strip shapes (sprocket-hole top edge, torn right edge via
  clip-path) — the GSAP scroll-scrub timeline itself was untouched,
  only the DOM/CSS of the same 4 ref'd nodes changed.
- De-duplication beyond the timeline: homepage "Who It's For" is now
  an asymmetric bento layout (2 featured cards + 4 compact ones)
  instead of a uniform 3x2 grid; how-it-works/page.tsx's FAQ is now a
  real accordion (`<button aria-expanded>`, keyboard-accessible, one
  open at a time) instead of 6 always-open identical cards.
- Token cleanup: TiltCard.tsx's stray `#1F1F1F` border -> `#2A2A3E`;
  Footer.tsx's off-palette `#444`/`#333`/`#0B0B14` -> the standard
  `#7A7A9A`/`#4A4A6A`/`#0F0F18`.
